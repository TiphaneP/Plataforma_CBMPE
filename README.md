# Plataforma CBMPE

Projeto acadêmico desenvolvido no curso de Engenharia de Software do IFPE – Campus Belo Jardim, na disciplina de Engenharia de Requisitos.

A proposta é desenvolver uma plataforma para facilitar a solicitação e emissão de certidões de ocorrência do Corpo de Bombeiros Militar de Pernambuco (CBMPE).

### Organização

As atividades e os requisitos do projeto são organizados por meio de GitHub Issues e GitHub Projects.

### Status

🟣 Em desenvolvimento — Etapa de Engenharia de Requisitos.
